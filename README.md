# 🤖 AI Agents Automation System for Cinematic Content

نظام متكامل ومستقل لإدارة وأتمتة وكلاء الذكاء الاصطناعي (Multi-Agent System) لإنتاج الفيديوهات، الريلز، والمسلسلات القصيرة بجودة سينمائية واقعية، مع الالتزام التام بالضوابط الشرعية والقانونية وبأقل تكلفة تشغيلية.

## 👥 هيكلية نظام الوكلاء (6 Agents)

يحتوي النظام على 6 وكلاء مستقلين يعملون في حلقة برمجية مغلقة:
1. **المدير (Manager Agent):** للبحث المالي، سحب الهاشتاجات الرائجة (Trending)، واقتراح المواضيع.
2. **وكيل الإنتاجية والتطوير (Optimization Agent):** لضبط إعدادات النشر على المنصات ورفع نسب الاستبقاء.
3. **وكيل الرقابة الشرعية (Islamic Compliance Agent):** لضمان خلو المحتوى من القذف والتشهير ومطابقته للشريعة الإسلامية.
4. **وكيل الرقابة القانونية (EU Law Agent):** لفحص حقوق الملكية وسياسات المنصات وقوانين الاتحاد الأوروبي الرقمية.
5. **وكيل الإنتاج والربط البرمجي (Production Agent):** لربط الـ APIs المجانية وتوليد الصوت البشري والمونتاج الهجين.
6. **وكيل التفاعل والردود (Engagement Agent):** لمراقبة التعليقات والرد عليها تلقائياً في أول ساعتين لرفع التفاعل.

## 🛡️ بروتوكولات الحماية والتشغيل (Core Protocols)

* **بروتوكول حد المحاولات الثلاث الصلب (3-Retry Hard Cap):** لمنع الحلقات اللانهائية (Infinite Loops) وحماية ميزانية السيرفر من النفاد عند حدوث خطأ أو رفض برمي.
* **الإنتاج الهجين (Hybrid Cinematic):** البحث عن لقطات حقيقية أولاً من مكتبات المشاع الإبداعي والاعتماد على ميزات الـ Photorealistic لمنع المظهر البلاستيكي المصطنع للذكاء الاصطناعي.
* **التعلم الذاتي المستقل (Autonomous Self-Learning):** تحديث ملفات التوجيه (System Prompts) داخلياً بناءً على الفيديوهات الأكثر ربحية وتفاعلاً بدون تدخل بشري.

## ⚙️ بيئة العمل والتقنيات المستخدمة
* **اللغة الأساسية:** Python
* **إطار عمل الوكلاء:** CrewAI / LangGraph
* **النماذج النصية والرقابة:** Google Gemini Flash API (الخطة المجانية)
* **توليد الصوت البشري:** Edge-TTS
* **المونتاج البرمجي:** MoviePy
* **واجهة التحكم:** Telegram Bot API
