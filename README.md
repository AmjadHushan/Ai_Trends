## 🏗️ هيكل النظام والوكلاء المعتمد (System Structure)
يعتمد النظام على 5 وكلاء ذكاء اصطناعي مستقلين (5 Core Agents) يعملون بتناغم تتابعّي صارم وفق مبدأ فصل السلطات لحماية خط الإنتاج:

1. 👤 وكيل الإدارة والتخطيط (AI Manager Agent): 
   العقل المدبر المسؤول عن رصد الترندات، صياغة الخطط التسويقية لرفع الأرباح، وتوليد الكلمات المفتاحية البصرية وتمريرها للكاتب.
   
2. 🛡️ وكيل الرقابة الشرعية (Islamic Compliance Agent): 
   السلطة الرقابية العليا الممتلكة لحق الفيتو المطلق وفحص الفكرة والنص والمخرج النهائي شرعياً لمنع التجاوزات.
   
3. ⚖️ وكيل القانون الأوروبي وسياسات المنصات (EU Law Agent): 
   المسؤول عن فحص الامتثال لقوانين (EU AI Act & GDPR)، ومطابقة رخص المشاع الإبداعي والترددات الصوتية لتفادي المخالفات وحظر القنوات.
   
4. ✍️ وكيل كتابة المحتوى والسيناريو (AI Writer Agent): 
   مصنع النصوص المسؤول عن صياغة السيناريوهات وتجزئتها، وتطبيق بروتوكول التعديل الموضعي (Granular Patching) والتعلم التراكمي عند الرفض.
   
5. 🎬 وكيل الإنتاج والربط البرمجي الموحد (AI Production Agent): 
   الوكيل التنفيذي المسؤول عن تشغيل أدوات المونتاج تتابعياً (توليد الصوت عبر Edge-TTS، الأفاتار والـ Lip-sync، وسحب اللقطات ورندرة الفيديو النهائي بـ MoviePy).

* 📱 واجهة التحكم والأزمات (Telegram Central Bot): 
  بوابة برمجية وسيطة خارج الحاوية الرسومية لاستقبال التقارير والفيديوهات، وإدارة نافذة الـ 6 ساعات الحتمية للمطور البشري قبل النشر الذاتي.
